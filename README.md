# Digi Companion

Digi Companion is a desktop application designed to help elderly users with their daily lives through a simple, accessible, and easy-to-use interface.

It brings together useful tools such as an AI assistant, medication and appointment reminders, blood pressure tracking, and other everyday features in one place. The goal is to make technology less intimidating and help seniors stay organised, independent, and connected.

## Features

* AI Assistant
* Medication & appointment reminders
* Blood pressure logging
* Simple and accessible interface
* Large, easy-to-read UI
* Designed specifically for elderly users
